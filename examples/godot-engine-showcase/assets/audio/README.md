# Demo sound effects

Original OGG selections from Kenney Interface Sounds 1.0 and Impact Sounds 1.0.
Both packs are CC0; original licenses are included alongside the selected clips.
Sources: https://kenney.nl/assets/interface-sounds and https://kenney.nl/assets/impact-sounds

Event mapping and per-event mix: `res://data/audio_manifest.json`.
No generated tones, permanent background drone, or runtime download fallback.
These samples are cosmetic feedback; they do not define gameplay rules.
