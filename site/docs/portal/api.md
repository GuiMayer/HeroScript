# Consumir a API

A HeroScript executa regras e publica resultados autoritativos. Seu cliente envia intenções e apresenta os fatos confirmados, sem recalcular gameplay.

## Seu primeiro fluxo

1. [Execute o quickstart](../api/getting-started.md).
2. [Entenda IDs, idempotência, concorrência e erros](../api/contracts.md).
3. [Leia a sessão compacta](../api/interactive-session.md).
4. [Avance a run e execute o combate](../api/runs-and-combat.md).
5. [Recupere histórico e eventos](../api/events.md).

## Construir a experiência

- [Deck ativo e reserva](../api/deck-loadouts.md), [pagamentos](../api/card-payments.md) e [recompensas exclusivas](../api/reward-decisions.md).
- [Inscrições](../api/inscription-loadouts.md), [compartimentos](../api/deck-compartments.md) e [suporte](../api/support-loadouts.md).
- [Sandbox, timeline e branches](../api/combat-sandbox.md), conforme as capacidades do modo.
- [Governança e estabilidade](../api/governance.md): documentação não promove recursos experimentais a estáveis.
