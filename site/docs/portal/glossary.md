# Glossário

| Termo | Significado |
| --- | --- |
| Run | Sessão autoritativa que reúne progressão, encontros e histórico. |
| Setting | Composição de conteúdo e regras que configura um jogo. |
| Package | Unidade de autoria e composição de definições. |
| Revisão de conteúdo | Identidade imutável do conteúdo vinculado à run. |
| Seed | Entrada da execução determinística; não substitui revisão e identidades de comando. |
| Comando | Intenção enviada ao servidor para uma transição validada. |
| Recibo | Resultado confirmado de um comando, recuperável pela mesma identidade. |
| Sequence / step | Versões observadas usadas no controle de concorrência; não são contadores intercambiáveis. |
| Ator | Participante genérico do estado de jogo. |
| Recurso | Quantidade configurada; o nome não atribui uma regra hardcoded. |
| Componente | Parte declarativa de um container ou entidade. |
| Zona | Configuração de propriedade/fluxo de cartas, não uma finalidade universal fixa. |
| Módulo | Alternativa configurável de composição do deck. |
| Inscrição | Equipamento que altera atributos do personagem. |
| Modificador de carta | Item ou transformação aplicado a uma instância de carta. |
| Replay | Reconstituição/verificação do histórico com as entradas e regras vinculadas. |
| Branch | Histórico derivado configurável, separado do ramo de origem. |
